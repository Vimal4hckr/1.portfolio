# 🎨 Cinematic Portfolio

A modern, cinematic portfolio website built with **React, TypeScript, and Vite**. The project combines smooth scrolling, animations, and modern styling to create an engaging web experience.

🌐 **Live Website:** [View Portfolio](https://1-portfolio.vimalg454.workers.dev/)

💻 **Source Code:** [GitHub Repository](https://github.com/Vimal4hckr/1.portfolio)

## ✨ Features

- Modern React component architecture
- TypeScript for maintainable, type-safe code
- Smooth scrolling powered by Lenis
- Motion effects and animations using Framer Motion
- Tailwind CSS integration for styling
- Fast development server powered by Vite
- Code linting with Oxlint
- Production-ready build process

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| React | Building interactive user interfaces |
| TypeScript | Type-safe JavaScript development |
| Vite | Development server and build tooling |
| Tailwind CSS | Utility-based styling |

## 🚀 Getting Started

### Prerequisites

Install Node.js and npm before starting. Verify the installation:

```bash
node --version
npm --version
```

### 1. Clone the Repository

```bash
git clone https://github.com/Vimal4hckr/1.portfolio.git
```

### 2. Navigate to the Project

```bash
cd 1.portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## 📦 Available Commands

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Checks TypeScript and creates a production build |
| `npm run preview` | Previews the production build locally |
| `npm run lint` | Runs Oxlint |

### Build for Production

```bash
npm run build
```

The production output is generated in the `dist/` directory.

The portfolio is deployed at:

